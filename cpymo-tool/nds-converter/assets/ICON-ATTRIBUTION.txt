  All Windows ICO, macOS ICNS and GUI PNG variants share this source.
  macOS alone uniformly scales the complete image to 80% and centers it
  on a transparent canvas. No extra crop, edge erosion, corner mask or
  horizontal compression is applied. Frozen Mac applications retain the
  native Bundle ICNS instead of replacing the Dock tile with a Tk PNG.
  Windows ICO and its small GUI PNG retain the original direct resampling.
  There is no second round-corner mask, 16px erosion or horizontal compression.
  The former 04 pixel-art / perimeter-cleanup icon is superseded, not bundled
  as an alternative design. Git history is not rewritten.

Nintendo DS program:
  Its external banner, splash and internal fallback icon use the original
  FULL-SQUARE composition at 32x32, 15 opaque RGB555 colors, with no rounded mask.
  This desktop icon generator does not write those NDS resources or any
  game's own cover/icon. See cpymo-backends/nds/assets/ICON-ORIGIN.md.
