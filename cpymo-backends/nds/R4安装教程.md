# R4 安装教程

适用普通 DS / DS Lite、能正常启动的 FAT/DLDI 烧录卡。请先备份 TF 卡存档。
保留现有 R4 内核，不需要为了本引擎格式化卡片。

## 已有转换好的游戏

1. 将配套包内的 `cpymo-nds.nds` 放到 TF 卡根目录。
2. 游戏目录应为 `pymo/games/游戏名/gameconfig.txt`，同一层有
   `script` 和 `nds-cache`。避免套上两层 `pymo` 或额外的安装包文件夹。
3. 同一引擎可读取多个游戏，启动后在游戏列表选择。
4. 在电脑安全弹出 TF 卡，装回 R4，在 R4 菜单运行 `cpymo-nds.nds`。

例如：

```text
TF卡根目录/
  cpymo-nds.nds
  pymo/
    games/
      GameOne/
        gameconfig.txt
        script/
        nds-cache/
        save/
```

更新引擎只需更新根目录的 ROM。现有 NDS 缓存、游戏和存档可继续使用。
转换器输出的新空 `save` 不要覆盖自己的存档；不要默认导入 S60/安卓存档。

## 转换自己的游戏

1. 在 Windows 电脑完整解压配套包，不要只取出转换助手 EXE。
2. 双击“启动转换助手.bat”，选择原游戏 ZIP/APK 或含 gameconfig 的文件夹。
3. 若包内有多个平台版本，在列表中选择一个；一般优先 S60v3。
4. 选择保存位置，点击“开始转换”。无需另装 Python 或 FFmpeg。
5. 转换结束打开结果目录，先看“安装必读”和“转换结果.json”的警告，再按上节放卡。

输入支持 S60v3/S60v5/安卓的 PyMO 数据结构，不是任意安卓游戏。
源包、定稿脚本、汉化和署名不改。视频从新输出省略，播放指令安全略过。
缺失音频可能静音，缺字可以按明确选项显示方框；警告保存在转换记录中。
目前音频缓存优先保证流畅，游戏安装体积可能明显增大。

## 操作

A/触控确认或继续；X菜单；菜单内B返回/取消，剧情中按住B隐藏文字。
Y开关辅助屏，L交换上下屏；辅助触屏关闭时第一次触控仅唤醒。
R按设置快进；START快速保存到标准存档1，SELECT快速读取标准存档1。
合盖暂停并静音，开盖继续。字号和已读变灰按游戏分别保存。

游戏内 X → 设置 → “立绘特效(全局)”可关闭立绘渐变与移动，切换时直接显示最终状态；
对全部游戏生效。背景转场、透明遮罩保留，读图所需时间仍存在。

“需要转换”通常表示误选了原始包，或目录层级/缓存不完整；先检查转换记录和布局。
FAT错误先检查卡片是否能正常读写、R4内核和文件是否完整。模拟器成功不等于所有卡都兼容。
反馈时提供引擎版本、游戏来源平台、主机/卡型号和复现步骤；存档先自行保留备份。
